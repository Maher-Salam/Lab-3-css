# Norrgläntan

En responsiv webbplats för turistmålet Norrgläntan.

## tekniker

- Html5
- CSS (flexbox, grid, media-query)

## Webbplatsen består av

- Header med en logotyp och namnet på platsen Norrgläntan
- Navigering som byter utseende beroende på stor eller liten skärm
- en hero-bild med rubrik, introduktionstext och knapp
- tre klickbara puffar
- en call to action section för att planera besöket
- footer med logotp, kontak och länkar
